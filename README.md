
# EagleLizard Dotfiles

dotfiles.

## tmux

```sh
ln -s ~/repos/dotfiles/.tmux.conf ~/.tmux.conf
```

## ghostty

```sh
ln -s ~/repos/dotfiles/config.ghostty ~/Library/Application\ Support/com.mitchellh.ghostty/config.ghostty
```

## pi

Run setup script:

```sh
curl -o- https://raw.githubusercontent.com/EagleLizard/dotfiles/main/pi/pi-setup.sh | bash
```
